# SourceLens 企业数据治理宣传视频脚本

## 成片定位

- 时长：2 分 40 秒左右；16:9 横版，适合官网、销售演示与展会循环播放。
- 受众：企业 IT、数据治理负责人、业务负责人和一线知识工作者。
- 核心主张：**数据无需建库，知识分域可用，Agent 全程可控。**
- 视觉基调：深色企业科技感；真实产品录屏为主，动效只负责解释数据、权限和 Agent
  的关系。

> 口播中的“按需读取”是指 Agent 在受控工作区中查找和推理，不等同于跳过企业既有
> 数据源权限；“分域”在本产品中由数据源/目录绑定与助手访问授权实现，而非宣称行级
> 数据权限。

## 核心优势：从“建库”到“理解”（0:15–0:43）

| 画面 | 旁白 | 屏幕字幕 |
| --- | --- | --- |
| 左侧是“更新数据 → 切片 → Embedding → 重建索引 → 检索”的循环；右侧是“同步更新 → Agent 按需读取 → 回答”。传统流程淡出。 | SourceLens 不要求预先构建向量库。数据源同步完成后，Agent 即可在授权工作区中按需搜索、读取和推理；不必等待新的切片、Embedding 或索引任务。 | 数据更新后，无需重建知识库 |

## 建议录屏素材清单

1. 数据源管理：新增 GitHub、GitLab 或飞书数据源，展示同步状态与范围；准备一段“资料更新后同步，随即发起问答”的连续录屏。
2. 用户、用户组与角色：创建业务组，分配平台功能可见性。
3. 助手编辑：配置名称、能力、数据目录、模型、Skill/MCP/插件绑定、可见范围。
4. 智能协作：一个协作助手与两个或三个专长助手的成员配置。
5. 聊天：一次真实的“查找—阅读—回答”过程；素材须使用脱敏演示数据。
6. 安装：终端执行一键安装、健康状态、首次登录和模型配置。

## 制作注意事项

- 不要在录屏或字幕中展示 API Key、连接凭据、真实内部地址或未脱敏业务资料。
- “答案可追溯”演示应展示相对文件路径或允许公开的文档名称，不展示运行容器路径。
- “权限”演示聚焦当前已实现的角色功能可见性、助手对用户/用户组授权、助手资源绑定；不要用“数据行级权限”“全链路合规认证”等未验证措辞。
- 若用于对外投放，建议另做 30 秒版本：保留片头、核心优势、三层控制、三步创建和落版。
