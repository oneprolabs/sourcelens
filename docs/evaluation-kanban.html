指标口径

SourceLens 是 Harness-based Agentic RAG：既评估任务是否完成，也评估是否真的找到了证据。

指标类别计算方式数据来源需要 LLM
Citation AccuracyRAG 质量引用 path / symbol / 起止行与仓库快照比对Run.citations否
FaithfulnessRAG 质量复核裁决 supported / unsupported / inconclusivedeepagents.evidence.verified复用 decision
Answer CorrectnessRAG 质量对 expected_answer / expected_facts 打分新增 rubric是
Context CoverageRAG 质量expected_sources 是否被检索命中trace 证据 + 引用否
Task Completion执行质量由 trace 派生，不直接读 Run.outcomeRunTraceEvent否
Tool Success Rate执行质量tool.completed / (completed + failed)RunTraceEvent否
Efficiency执行质量轮次、重试、耗时、token 与基线对比trace + 计量否
Isolation / 越权可靠性确定性测试：跨助手、跨数据源、无权限引用测试用例否

看板口径

  • 待决策：需先确认产品 / 技术口径，不能按假设实现。
  • 待开始：设计已明确、代码未开工。
  • 进行中：已开工，未提交或未自测。
  • 待测试：需 dev 栈、真实链路或浏览器验收。
  • 已完成：代码提交且验收条件全部满足。
  • 点击卡片底部按钮切换状态，状态存在浏览器本地。

明确不做

  • 不做在线实时评估（每次提问都打分）。
  • 不做新的 Agent Runtime / Trace Collector。
  • 不引入外部评估服务或新基础设施。
  • 不做安全性 LLM 评分门禁，越权只用确定性测试。
  • 不做完整人工标注平台（仅最小标注与导入）。
