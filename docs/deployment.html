SourceLens 部署拓扑

Docker Compose · 8 服务 · bridge 网络 backend_network · 卷挂载数据持久化

部署图 (Deployment Diagram) — 结构性图形。展示容器/进程节点、宿主机卷、端口暴露与网络拓扑,以及健康检查与重启策略。

Backend Cluster (3 角色同镜像)

  • backend-api: gunicorn · :8000 · /health probe
  • backend-worker: celery worker · queue=lens/celery
  • backend-scheduler: celery beat · DatabaseScheduler
  • 同一镜像 sourcelens-api 启动不同 command
  • health-gated depends_on · start_period 120s

Frontend Container

  • 独立镜像 sourcelens-ui · in-container Nginx
  • expose 80 (内部) · 外部经 nginx 代理
  • Vue 3 SPA · axios → /api/*
  • 无外部端口暴露, 仅 backend_network
  • depends_on: 服务启动即可 (无 healthcheck)

LensNode Container (独立镜像)

  • sourcelens-lensnode · /opt/lensnode pkg
  • WS → backend-api:8000/ws/lens/lensnodes/
  • HTTP → backend-api:8000/api/lens/lensnode/ai-gateway/
  • LENSNODE_NAME/TOKEN/HEARTBEAT_INTERVAL_S
  • 可独立 docker-compose 启动 (host.docker.internal)

Data Plane (3 容器)

  • postgresql: postgres:17 · :5432 · custom postgresql.conf
  • redis: redis:alpine · :6379 · broker+Channels
  • data/workspace: bind mount · api+lensnode 共享
  • initdb.d/ · md5 auth · healthcheck PGPASSWORD psql
  • redis-cli ping · 10s interval

Host Volumes (持久化)

  • ./data/postgresql/data · DB 持久
  • ./data/redis · AOF/snapshots
  • ./data/workspace · /workspace 共享
  • ./data/storage · 静态/上传
  • ./data/logs/* · 各类服务日志
  • ./docker/nginx/certs · TLS

Network & Health

  • backend_network (bridge driver) · 所有服务共享
  • 对外仅 nginx :10080/:10443
  • 容器间 DNS 解析 (backend-api, postgres, redis)
  • 所有服务 restart: unless-stopped
  • healthcheck interval 10-30s · retries 3-5
