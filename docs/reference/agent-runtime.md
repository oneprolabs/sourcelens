# Agent 运行约定

LensNode 使用 deepagents 执行循环，保留冻结能力、预算、checkpoint 恢复和暂存附件发布。
必需中间件、工具与依赖升级要求见 [LensNode 运行时契约](../decisions/002-lensnode-runtime-contract.md)。
本文描述当前代码行为，不代表生产部署或历史 Run 已重新验收。

## 检索与来源

`search_workspace` 默认按不区分大小写的完整字面短语匹配，保留空格、标点和中文，
仅 `|` 或 `｜` 分隔 OR alternatives。正则表达式须显式使用 `regex=True`。
依赖旧拆词行为的调用方须改为显式 alternatives。

存在转换 sidecar 时，搜索使用与 `read_workspace_file` 相同的规范转换正文，返回
原始来源路径与转换正文行号。重叠命中按来源路径和行号去重；不同位置的重复正文保留。
所有选定根目录参与后才排序和限制结果。

来源 include scope 与请求 glob 在原始文档路径取交集，即使正文存放在 sidecar 中。
支持递归、basename、brace alternatives 和排除 glob；导航同样先应用范围，再限制结果。
无正文匹配时最多返回八个、合计 2,000 字符的导航路径，不作为答案证据。
较大文件清单使用 `find_files`；明确要求列出文件的任务可使用其结果作为证据。

普通执行和强制综合均须遵守用户已确定的平台与操作范围。文档条件不自动构成事故根因，
也不能独自证明代码抛错位置或状态归属；缺少实例或实现证据时须明确说明。

## 模型协议与摘要恢复

未解析的 DSML 工具请求在发布和工具执行前丢弃。普通流式和非流式模型调用可在
原合法对话后追加原生工具调用格式纠正，最多重试一次；无工具时要求纯文本。
坏响应不写入 assistant 历史，两次调用均计量，并沿用取消和网关预算限制。
第二次协议错误继续传播。控制判断沿用自身回退，不套用普通对话的纠正重试。

摘要器仅对 `httpx.TransportError` 重试，最多三次尝试。协议错误、空摘要或无效占位摘要
保留原历史，发出 `deepagents.summarization.failed`，并停用当前中间件实例后续压缩。
取消、硬预算耗尽和未知异常继续传播。保留历史可能增大上下文，不能保证任意长度的调查
都能继续。恢复事件与轨迹显示见 [Run 实时轨迹](run-trajectory.md)。

## 预算收尾与证据

触及 token 预留线时，若已有无待执行工具的完整答案，先完成 graph 后置校验并允许自然
结束。需要纠正、仍有待执行工具或模型异常终止时，执行受限综合；不会只因触及预留线
重写正常答案或将其标为 partial。附件写入窗口见 [交付物发布](../decisions/003-reviewed-deliverable-publication.md)。

强制综合保留运行时 system 规则，将内部控制放入 system 消息，并将原始问题原样放在
最后一条 user 消息。原始问题决定回答语言，Profile 语言仅作 fallback。
有界上下文分别为用户约束、先前答案和各工具结果预留空间，明确标注省略内容；
嵌套 JSON 中的分页元数据标为来源报告的元数据，不据此宣称唯一记录已完整读取。

单次执行在可替换的 graph 消息之外保留有界工具摘录、参数和元数据；摘要移除已观察结果
后，综合仍可引用这些材料，并补回缺失的原用户上下文。该机制不能恢复本次执行从未观察
到的结果。证据中间件在预算或轮数耗尽、尚无首个答案时也接收已观察工具材料。

EvidenceGate 在外层文件系统中间件转存大结果前，额外保留最多 32 条有界原文。
审核时按 call id 和工具名匹配，替换仅含预览的图消息。转存本身不意味着缺失审核材料；
真实来源缺口、超出单条或总容量的结果仍须标记。

结构化审核可用显式引用表共享重复值，以列/行表示统一对象列表，并带编码标记解析
JSON 工具正文。编码保留事实与覆盖标记，使用保留键避免源字段冲突；不总结或筛选证据。
无损编码后仍超过配置字符限制时，保持审核不完整。审核调用容量见 [Decision Plugin](decision-plugins.md)。

## 图执行最终判定

`agent_runtime/finalization.py` 在执行后刷新扩展证据，检查完成条件与附件要求，审核选定
答案，再统一解析 outcome。`FinalizedRun` 保存答案、outcome、终止详情、stop reason 和
接受的附件 manifest；command manifest 继续适配后端最终消息发布协议。

先前执行、来源覆盖或完成检查失败不能被成功审核抹除。来源有缺口时可保留已校验附件；
完成检查失败则撤下候选附件和不受支持的断言。明确要求附件时，缺少文件不能算完成。
manifest 是附件状态的依据，最终判定时与运行证据对齐。

执行中可要求有界纠正，最终判定不重启循环或授予额外重试预算。中间件保留最近非空的
有界工具视图；答案改写后使用该材料及最新扩展证据重审，新工具材料使旧 verdict 失效。
该缓存不是无限历史，也不证明所有原始来源已读完。

审核异常，或任一已配置门禁因超时、无效结果、低置信度、调用预算耗尽而没有有效 verdict，
保留产出并以 `partial / review_unavailable` 结束。未知判断不能默认通过，也不能在没有
反证时要求模型因审核服务故障重写。`review_material_incomplete` 专指材料缺失或截断。
取消和硬网关预算异常继续传播，最终审核后再次检查取消。

该统一收尾针对 graph 执行；不表示 direct/planned 路径已全部重写。
活动报告仍由业务扩展负责，见 [活动汇总契约](activity-report-contract.md)。

## 网关与计时

Django 启动时初始化 LiteLLM，避免并发首请求触发循环导入；导入成本转移到启动阶段。
SSE 消费者断开时通知工作线程停止，不等待同步网络读取。线程负责生成器关闭、预算锁
释放并抑制迟到的队列写入；已阻塞的供应商读取仍依赖配置超时，不能承诺立即取消。

网关错误日志尽可能包含 Run UUID。传输错误、模型用量记录和问答结果是不同信号，
用量表全部成功不表示问答成功。
终态携带原始 `node_enqueued_at` 与本次尝试的 `node_sent_at`，后端记录接收时间及
单调时钟处理耗时。节点时间用于排队测量；跨节点时间差含时钟偏差。trace `duration_ms`
描述本次节点执行，数据库 Run 时长还包含准入、等待及终态传递，不能追溯归因历史延迟。
