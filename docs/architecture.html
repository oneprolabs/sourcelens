SourceLens 系统架构

Django REST + Vue 3 SPA · Agentic Code Intelligence · 多容器微服务

架构图 (Architecture Diagram) — 结构性图形。展示 SourceLens 系统的整体组件拓扑、容器边界与数据流方向。

Frontend Entry (User-facing)

  • User Portal: Dashboard / AIQuery / Auth
  • Lens Workspace: Assistants/Chat/History + SSE
  • Admin Console: User/Role/Group/LLM/Task/Notif
  • LensNode Console: Node/Source/Skill/MCP/Setting
  • Nginx :10080/:10443 reverse proxy → backend-api

Backend Core (Django)

  • accounts: JWT + Google OAuth + Role/Permission
  • lens: Agentic Code Intelligence (14 tables)
  • core: settings/celery/middleware/registry
  • core.urls: /health /swagger /admin /api/* aggregation
  • LensNodeAIGatewayView: proxy LLM requests

agentcore Packages (3)

  • agentcore-task → /api/v1/tasks/ (unified task)
  • agentcore-metering → /api/v1/admin/ (LLM usage)
  • agentcore-notifier → /api/v1/admin/notif/ (Feishu)
  • Installed from the configured Python package index
  • Mounted as Django app via INSTALLED_APPS

LensNode Sandbox

  • Standalone container sourcelens-lensnode
  • WebSocket → /ws/lens/lensnodes/ (15s heartbeat)
  • HTTP → /api/lens/lensnode/ai-gateway/
  • executor: Claude Code / Codex subprocess
  • /workspace shared volume, RO DataSource mount

Storage & Middleware

  • PostgreSQL 17: primary DB + django_celery_beat
  • Redis Alpine: Celery broker + Channels layer
  • data/workspace: lensnode ↔ api bidirectional
  • data/storage: gunicorn logs + static files
  • docker/postgresql: custom config + initdb.d

External Dependencies

  • Google OAuth 2.0 (dj-rest-auth + allauth)
  • Feishu/Lark (agentcore-notifier Webhook)
  • LLM Provider (OpenAI · Claude · GLM · Kimi)
  • Git/Jira/Feishu Docs (source_sync pull)
  • Unified metering via metering submodule
