# 每日研发汇总助手示例

本示例用于配置运营助手，汇总已授权仓库和任务系统的研发动态。
它不是预配置的组织、账号映射或定时任务。

## 配置

先为助手绑定可读取所选仓库/项目的 Connection 与 Plugin，或已安装且满足运行边界的
Skill。Jira 实例与认证方式以实际安装的 Plugin/Skill 为准。
不要将原始 Token、密码或内部服务地址复制进提示词。

设置项目范围、报告时区和经过确认的账号映射。定时运行前先手工验证一份报告的
覆盖范围、分页和时间边界；不能把权限失败或漏分页当作“当天没有活动”。

## 提示词模板

```text
请汇总报告时区中前一个自然日的研发动态。

范围：管理员指定的 GitHub/GitLab 仓库或组，以及 Jira 项目。
时间：按配置时区的昨日 00:00（含）到今日 00:00（不含），查询参数转换成
工具所需的时间格式。使用可用的授权工具，并处理分页。

按平台和项目列出提交或任务变化，附原始提交/任务的可点击 URL。
再按已确认的账号映射汇总；未知账号保留原名，不猜测身份。
提交信息保留原文，说明使用中文。按事实说明重要修复、交付与未决问题。

区分“查无活动”和“数据不可访问”，注明覆盖不足的范围。
不要根据提交数推断个人绩效，不要把计划写成已完成或已上线。

如需图表，生成自包含 HTML 文件作为交付物。正文、图表和计数必须一致；
缺失数据明确留空。最终给出覆盖范围、时间窗和数据来源。
```

HTML 交付文件的发布与可见性见
[审核后发布交付物](../decisions/003-reviewed-deliverable-publication.md)。
